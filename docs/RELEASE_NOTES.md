Graffalo Agent Bridge now connects to **https://graffalo.io** by default.

- Downloaded launchers use the default connection without configuration.
- Simplified setup instructions and terminal output.
- Same protocol 1 pairing, native Codex/Grok Build adapters, and diagram proposals.
- Native builds for macOS Apple Silicon/Intel, Linux ARM64/x64, and Windows x64.
- SHA-256 checksums and bundled MIT/third-party license texts.

This remains an **alpha**, not a signed installer or tray app. Live agent-account
and browser compatibility still need validation. Windows discovers native .exe
agents only; npm .cmd wrappers are not supported. OS protections may block unsigned
downloads. Installing this companion does not deploy Graffalo's Chat panel.
