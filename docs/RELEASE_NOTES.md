First standalone experimental release of Graffalo Agent Bridge.

- Native binaries for macOS Apple Silicon/Intel, Linux ARM64/x64, and Windows x64.
- Loopback pairing with an exact Graffalo origin and temporary session code.
- Native Codex App Server and Grok Build ACP adapters; no model API-key collection.
- Streaming replies, cancellation, and diagram proposals for review in Graffalo.
- SHA-256 checksums and bundled MIT/third-party license texts.

This is an **alpha**, not a signed installer or tray app. Live agent-account and
hosted-browser compatibility still need validation. Windows discovers native .exe
agents only; npm .cmd wrappers are not supported. OS protections may block unsigned
downloads. Installing this companion does not deploy Graffalo's Chat panel.
